# Bright-Coffee

## 📌 Overview

This project analyses coffee shop transaction data to identify sales patterns, product performance, and opportunities to improve revenue.

The analysis was completed using multiple data analytics and visualisation platforms.

## 🎯 Objectives

* Identify top-performing products
* Analyse revenue and units sold
* Identify peak sales periods
* Compare store and product category performance
* Identify trends and provide business recommendations

## 🛠️ Tools Used

* 🟦 Databricks
* 🟩 Power BI
* 🟨 Excel
* 🟪 Looker Studio
* 🟥 Lovable
* 🗄️ SQL

## 📊 Dashboards

| Platform      | Focus                        |
| ------------- | ---------------------------- |
| Databricks    | Product & Sales Performance  |
| Power BI      | Time & Sales Performance     |
| Excel         | Sales Trends                 |
| Looker Studio | Store & Category Performance |
| Lovable       | CEO Executive Overview       |

## 💡 Key Analysis Areas

**Products → Revenue → Time → Stores → Trends → Insights**

## 📈 Outcome

The project transforms raw transaction data into interactive dashboards that help identify sales patterns, high-performing products, and potential areas for business improvement.
